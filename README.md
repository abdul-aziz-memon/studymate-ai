# StudyMate AI

StudyMate AI is a friendly study buddy that turns tricky topics into clear, approachable explanations. It includes a study chat with image support, a landing page, and a creators page.

## Features

- Chat with an AI tutor designed to explain concepts simply.
- Attach images to questions.
- Switch between available themes.
- Runs locally with Node.js.

## Requirements

- Node.js 18 or later
- A Groq API key

## Getting started

1. Clone or download this repository.
2. Create a `.env` file in the project root and add your Groq API key:

   ```env
   GROQ_API_KEY=your_groq_api_key
   ```

3. Start the server:

   ```bash
   npm start
   ```

4. Open [http://127.0.0.1:3000](http://127.0.0.1:3000) in your browser.

Keep your API key private. Do not commit the `.env` file or share its contents.
