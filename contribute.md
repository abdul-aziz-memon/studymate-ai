# Contributing

StudyMate AI is a creator-owned project and is maintained by its creator. Pull requests are allowed, and contributions are welcome for the creator to review. The creator makes the final decision on whether a change is accepted or merged.

## Submitting a pull request

1. Fork the repository and create a branch for your change.
2. Keep the change focused and explain what it does in the pull request.
3. Check the affected pages and the Vercel `/api/chat` function in a deployment preview.
4. Open a pull request for review. Please do not include API keys, `.env` files, or other secrets.
